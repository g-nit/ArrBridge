# ArrBridge: IMDb → Radarr / Sonarr Chrome Extension

A lightweight, local-first Chrome extension that integrates directly into your browser's **Side Panel** to seamlessly bridge the gap between browsing **IMDb** and managing your media libraries in **Radarr** and **Sonarr**.

---

## 🚀 Key Features

* **Intelligent Page Detection:** Automatically extracts the IMDb `ttXXXXXXX` ID from active browser tabs and identifies whether the asset is a Movie or a TV Series.
* **TMDb Media Poster Engine:** Instantly fetches and renders the official movie/series poster inside the side panel when a valid TMDB API key is provided.
* **Direct Radarr & Sonarr API Integration:** Communicates entirely client-side directly with your servers to retrieve Quality Profiles, Root Folders, and Tags.
* **Instant Library Status Checks:** Checks if the media asset already exists in your instance before adding, disabling duplicates.
* **Safe Add Execution:** Performs native API lookups on your server to add the complete payload structure, configure monitoring, and request immediate background downloads.
* **Smart Content Recommendations:** Powered by the TMDb engine. Instantly lists similar titles based on your current page and displays their presence in your home libraries.
* **Privacy Focused & Secure:** Configured connection URLs, API keys, and access tokens never pass through third-party cloud servers. Everything is stored securely inside `chrome.storage.local`.

## 🛠️ Installation Guide

Follow these steps to load the unpacked extension in developer mode:

1. **Download and Extract:** Download the repository source file and extract the `.zip` archive to a dedicated folder on your local machine.
2. **Open Extensions Dashboard:** Open a new browser window and navigate to `chrome://extensions/`.
3. **Enable Developer Tools:** Toggle the **Developer mode** switch in the top-right corner of the dashboard to `ON`.
4. **Load the Unpacked Folder:** Click the **Load unpacked** button in the top-left menu.
5. **Select Root Directory:** Select the folder path containing the extension's `manifest.json` file.
6. **Open Extension Panel:** Navigate to an IMDb page, click the extension icon, or use your browser options layout shortcut to toggle the extension **Side Panel** view.

---

## ⚙️ Configuration

1. In the extension settings layout (or by clicking the ⚙ gear icon inside the Side Panel), enter your server credentials.
2. **URL Formatting:** The configuration engine features an **Automatic Protocol Fixer**. You can paste standard local addresses or IPs, and it will auto-format protocols and strip trailing slashes:
   * *Example Input:* `192.168.1.50:7878` \(\rightarrow\) *Saved Output:* `http://192.168.1.50:7878`
   * *Example Input:* `http://localhost:8989/` \(\rightarrow\) *Saved Output:* `http://localhost:8989`
3. Click **Test & Load Settings** to dynamically fetch your instance profiles.
4. Select your desired default **Quality Profile**, **Root Folder**, and optional **Library Tags**.
5. Click **Save All Settings**.

### Standard Network LAN Defaults

If you haven't altered your default port routing configurations during your initial media server setup layouts, your native system addresses usually follow:

* **Radarr default instance port:** `http://localhost:7878` or `http://192.168.1.X:7878`
* **Sonarr default instance port:** `http://localhost:8989` or `http://192.168.1.X:8989`

## 🧠 TMDb Recommendations Engine

Entering an optional **TMDB API Key** or a **TMDB API Read Access Token** in your Settings panel completely unlocks the discovery suite inside the side panel layout:

* **Automated Index Mapping:** The extension resolves the active tab's IMDb string ID directly through TMDb's lookups.
* **Discover Similar Titles:** Clicking the **Find Similar Titles** button generates a clean dashboard grid showing relevant recommendations.
* **One-Click Library Additions:** Instantly review what recommended content is missing or already present in your home database.

---

## 🔒 Security & Sandboxing

All network requests generated by the extension are dispatched directly from your browser engine using standard client-side `fetch()` APIs. The application runs entirely isolated without tracking behaviors or sending information to outside analytical proxies. **Never share your generated *Arr security API tokens or pass them to public GitHub repositories.**
