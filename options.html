IMDb → Radarr / Sonarr

Connect the extension directly to your *Arr servers. API keys are stored locally in Chrome.

Radarr

Optional. Choose the Radarr tag that matches your download-client setup. The tag is applied when the movie is added.

Sonarr

Optional. Choose the Sonarr tag that matches your download-client setup. The tag is applied when the series is added.

TMDB is optional and is only needed for the recommendation engine.

Radarr/Sonarr: Settings → General → Security → API Key. The extension never sends your API key to IMDb or a third-party server.
